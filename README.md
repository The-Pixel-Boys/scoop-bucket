# The-Pixel-Boys/scoop-bucket

Scoop bucket for The Pixel Boys tools.

## Install KYA

```powershell
scoop bucket add The-Pixel-Boys https://github.com/The-Pixel-Boys/scoop-bucket.git
scoop install shield-kya
```

The manifest downloads the `@shield-agent/kya` npm package, installs its dependencies, and exposes the `kya` and `shield-kya` binaries.
